# Словарь терминов

Справочник, а не playbook: сюда заглядывают, когда в задаче автора или в ответе тула
встретилось незнакомое слово. Термины Storaxis специфичны — «уровень» здесь не то же, что в
обычной иерархии, а «глава» вообще не сущность.

## Сюжет

| Термин | Что это |
|---|---|
| Событие | единица сюжета: что происходит, с кем и что меняет. Файл `events/nodes/<id>.json`, идентификатор `story_node:<guid>` |
| Ребро | связь двух событий одного уровня: источник **предшествует** цели. Другого способа задать порядок в графе нет |
| Детализация | разбор события на события помельче: глава на сцены, сцена на действия. Ребёнок — всегда детализация родителя, а не следующий пункт списка |
| Уровень | те же дети одного события, но со стороны хранения — файл `events/<id>.json`, идентификатор `story_level:<guid>`. **Дети одной ноды, а не все события одной глубины** |
| Границы уровня | служебные начало и конец уровня. Не события, содержимого не имеют; цепочка уровня идёт от начала до конца |
| Ветка | линия событий между расхождением и слиянием. Отдельной сущности нет: ветка это путь по рёбрам |
| Параллельные ветки | линии, выходящие из одной точки, из которых ни одна не является следствием другой. Ко времени отношения не имеет: события параллельных веток могут идти одно позже другого |
| Основная ветка | та, с которой читатель остаётся при разделении героев |
| Закадровая ветка | ветка, события которой в рендер не попадают. Закадровой бывает только ветка целиком; дельту такие события несут наравне со всеми |
| Таймскип | одиночное событие «прошло столько-то, случилось то-то». Не закадровое: в рендере это абзац перехода |
| Дельта | что событие меняет в мире — список правок свойств. Исчезновение выражается значением, а не снятием свойства |
| Свёртка дельт | дельта события с детализацией: осмысленный итог дельт потомков, а не их сумма. Изменились дочерние — помечается `Stale`; отражающая их — `Current` |
| Рендер | генерация финального текста силами LLM по этой модели. «Попадёт в рендер» значит «станет текстом книги» |

## Мир

| Термин | Что это |
|---|---|
| Объект мира | всё, что в мире есть: персонаж, предмет, место, группа, организация, концепт. Файл `objects/<имя>.json`, идентификатор `world_object:<guid>` |
| Вид объекта | `Character`, `Item`, `Location`, `Group`, `Organization`, `Concept` |
| Свойство | пара «предикат: значение» на объекте |
| Предикат | имя свойства: группа и имя через точку — `world.locatedAt`. Одноместный: у одного объекта одно значение |
| Группа предиката | всё до первой точки: `appearance`, `personality`, `state`, `world`, `knows`. Сущностью не является — живёт, пока есть свойство |
| Стартовые свойства | какой объект в начале книги. Состояние в любой другой точке — стартовое плюс дельты по хронологии |
| Свойство-связь | свойство со значением-ссылкой: `world.owner`, `world.locatedAt`, `world.partOf`. Записывается на стороне многих |
| `EntityRef` / `NodeRef` | значение-ссылка: на объект мира и на событие соответственно |
| Тег | сквозная метка, одна и та же на страницах кодекса и объектах мира. Файла у тега нет: живёт, пока стоит хотя бы на одной сущности |

## Объём

| Термин | Что это |
|---|---|
| Планируемый объём | во сколько знаков с пробелами событие развернётся в рендере (`renderLength`). Пусто и ноль — разное |
| Знак, страница, авторский лист | единицы: страница — 1250 знаков, авторский лист — 40 000, то есть 32 страницы. В файлах и тулах всегда знаки |
| Бюджет уровня | объём детализируемого события; у верхнего уровня — `renderLength` книги из `book.md` |
| Невязка | бюджет минус сумма по детям. Считается, только когда оценены все события уровня. Не ошибка, а рабочее состояние |
| Допуск | ±10–15%: в этих пределах невязка закрывается раскладкой остатка |
| Замок | `locked`: событие исключено из автоматической раскладки остатка |
| За кадром | `isOffscreen`: событие в рендер не пойдёт никогда. Флаг, а не нулевой объём, — это авторское намерение, а не число |

## Монтаж

| Термин | Что это |
|---|---|
| Лента | заданный порядок чтения. Файл `montage/<id>.json`, идентификатор `tape:<guid>` |
| Книга | верхняя лента. Отдельного понятия нет: лента рекурсивна |
| Главная дорожка | сама последовательность ленты: события и вложенные ленты |
| Черновая дорожка | отложенное: в рендер не идёт, но и забытым не считается |
| Вложенная лента | лента, размещённая на дорожке другой. Содержать себя — прямо или через цепочку — не может |
| Ячейка | одно конечное событие собранной ленты. В ячейках меряются позиции глав и интервалы разметки |
| Глава | разрез между двумя границами, а не сущность. Номер вычисляется по позиции |
| Граница главы | точка между ячейками; название главы лежит в ней |
| Разметка | интервалы со свойствами подачи: настроение, стиль, темп. Задание рендеру, а не свойство события |
| Перспектива | чей взгляд. Свойство ленты, не размещения |

## Кодекс

| Термин | Что это |
|---|---|
| Кодекс | иерархические заметки автора. Частью модели мира не является: место, где автор думает |
| Страница | один markdown-файл в `codex/`, идентификатор `codex_page:<guid>`. Заголовок — имя файла, родитель — папка |
| Выжимка (`summary`) | изложение страницы для модели: то, что уходит в контекст вместо всего текста |
| Ссылка в прозе | `[подпись](world_object:<guid>)` в тексте страницы. Упоминание, а не связь модели |
